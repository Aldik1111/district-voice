# Результат этапа 2 — локальный AI/NLP-движок

Проверено 12 октября 2026 года. Реализация находится в существующем district-voice, ветка feature/golos-rayona, HEAD 0ae22ad. Коммитов и git push не было. Сохранены прежние незакоммиченные изменения; импорт, исходные модели обращений и модуль маскирования не переписаны.

## Реализовано

- Десять категорий, русские и казахские признаки, локальные прототипы E5, сохранение исходного предложения, метода, оценки и неопределённостей. Ручная категория имеет приоритет; причина и версия правки сохраняются отдельно.
- Настоящие локальные embeddings intfloat/multilingual-e5-small. Входы для симметричного сравнения и прототипов имеют `query: `, векторы нормированы. Модель работает на CPU, до 512 токенов. Это общий embedding-модуль, а не специально дообученный городской классификатор.
- Резервный TF-IDF с символьными n-граммами 3–5 и ограниченной RU/KK-нормализацией. Отсутствие или сбой модели автоматически включает этот режим; фактический алгоритм и причина сохраняются в API и видны в интерфейсе. TF-IDF не называется полноценным семантическим AI.
- Технические дубли отсеивает существующий импорт. Для совпадающих публикаций сохраняются `republication_candidate` и `duplicate_of`; копии не прибавляют потенциальные оригиналы и не создают самостоятельное доказательство повторения проблемы.
- Конкретные случаи и повторяющиеся проблемы сохранены отдельно со связями на реальные обращения. Проверяются категория, конкретный адрес, даты, попарное сходство, противоречия и признаки копирования. Проверка всех пар не допускает слияния через цепочку слабых связей.
- Объяснения, период, территория, количество сообщений/источников, потенциальных оригиналов, неопределённости и статус `proposed` для групп. Все числа вычислены Python/SQL.
- SQLite: история запусков, снимки входных данных, результаты, членство групп, связи проблем со случаями и аудит категорий. Повторный запуск создаёт новую запись. Сбой не уничтожает предыдущий результат, правки делают старые результаты устаревшими.
- Интерфейс /analysis: запуск, выбор метода, история, случаи, проблемы, доказательства, замечания и ручная категория. Исторические доказательства показывают снимок выбранного запуска.

## Запуск и ограничения

Подробные команды Windows — в корневом README.md. Установка выполнена в backend/.venv и frontend/node_modules. Python в глобальном PATH не найден: текущая venv создана на доступном Python 3.12.14, её python.exe можно запускать напрямую.

Серверы: 127.0.0.1:8000 (API) и 127.0.0.1:3000 (frontend). SQLite — backend/data/district_voice.db. Остановка серверов — Ctrl+C в соответствующих терминалах; если они запущены агентом в фоне, сначала остановить эти процессы перед повторным запуском на тех же портах.

Локальный режим одного оператора без аутентификации. Лимиты 5 МБ/5000 строк/60 столбцов. Никаких внешних AI-вызовов. analysis_status=pending. Нет классификации, нормализации адресов, группировки, карточек системных проблем, утверждения сводки и экспорта отчёта. Полная функциональность MVP не заявляется.
