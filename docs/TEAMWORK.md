# Организация разработки

Владелец «Голоса района» отвечает за весь проект: frontend, backend, базу данных, AI и интеграцию. Три участника хакатона теперь создают отдельные проекты. Старые инструкции participants/ сохранены как исторический материал.

Работать в feature-ветке. Не отправлять изменения напрямую в main. Не перезаписывать чужие незакоммиченные изменения. Изменения API проверять одновременно на сервере и в интерфейсе. Реальные обращения, персональные данные, базы SQLite, ключи и пароли не хранить в Git.

Готовность означает выполненный пользовательский сценарий с реальным API и сохранением после перезапуска. Фиксировать выполненные проверки и ограничения. Не показывать искусственные числа как результаты анализа; демонстрационный набор всегда обозначать.

Текущий план — PLAN.md; состояние этапа — HANDOFF.md; технический контракт — ARCHITECTURE.md.
