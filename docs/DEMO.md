# Демонстрация «Голоса района» за 3–5 минут

Все данные набора вымышлены. Не представлять их как обращения реальных жителей. Приложение работает локально: frontend http://127.0.0.1:3000, FastAPI http://127.0.0.1:8000. Команды запуска — в README.

## Подготовка

- Использовать `data/demo-180.csv` или кнопку **«Загрузить демоданные»**. Файл содержит 180 строк на русском и казахском; эталон — `data/demo-180-gold.json`. Генератор: `backend/.venv/Scripts/python.exe scripts/generate_demo.py` из корня.
- Модель E5 уже установлена локально на проверенной машине. При отсутствии модели приложение честно покажет TF-IDF. На холодном старте оставить время на загрузку; проценты обработки не имитируются.
- Повторный импорт безопасен: уже существующие записи не добавятся повторно. В подготовленной базе сохранено 186 обращений (176 из большого набора и 10 прежних демонстрационных).
- Для повторения всех шагов выполните **новый анализ**. Он создаст новые предложения; ручные решения прошлого запуска останутся в истории и не перенесутся автоматически. Утверждённые сводки останутся доступны. Базу удалять не нужно.

## Сценарий выступления

**0:00–0:30 — Обзор.** «Это рабочее пространство аналитика. Числа и графики рассчитаны по локальной SQLite, никаких фиксированных показателей. Мы видим сообщения, предполагаемые копии, локальные случаи и повторяющиеся проблемы. Решение остаётся за человеком».

**0:30–1:00 — Импорт.** Открыть «Загрузка данных» → «Загрузить демоданные». Показать сопоставление полей, русский и казахский текст. Переключить «Только замечания»: две неверные даты и два технических дубля. Нажать «Подтвердить импорт». На пустой базе: принято 176, отклонено 2, дубли 2; при повторной загрузке: принято 0, отклонено 2, дубли 178. «Повторное сохранение не увеличивает число обращений».

**1:00–1:40 — Анализ.** «Перейти к анализу» → «Запустить новый анализ». Дождаться реального завершения. Показать фактический метод. «Модель работает на устройстве, тексты не отправляются во внешние API. Одинаковая тема без общего места и периода недостаточна для объединения».

**1:40–2:50 — Проверка воды.** «Все группы», поиск `абай 150`. Открыть группу с SYN-021 среди подтверждающих обращений. В проверенном запуске она содержит 15 записей. Прочитать SYN-021: речь об отдельном внутреннем ремонте крана мастерской. «Совпали тема, адрес и дата, но этот текст не подтверждает общее отключение. Алгоритм ошибся; аналитик исправляет связь».

Нажать «Исключить обращение», выбрать SYN-021, указать основание и сохранить. Показать 14 оставшихся сообщений, историю «до/после», обновить страницу. Исходная запись остаётся в реестре. Через «Название и категория» задать название «Отключение воды · Абая, 150». Подтвердить группу с комментарием. Если другая версия модели оставила SYN-021 отдельно, честно показать, что ошибка не воспроизвелась; не выдавать ручное добавление за ошибку AI.

**2:50–3:20 — Повторяемость.** Поиск `сейфуллин 220`, открыть повторяющуюся проблему: 42 сообщения, три отдельных случая (1 и 16 сентября, 1 октября). Проверить доказательства, подтвердить. «Мы разделяем отдельное происшествие и повторение на одной территории; общую техническую причину система не устанавливает».

**3:20–4:30 — Сводка.** «Отчёты»: выбрать 01.09.2026–09.10.2026 и все территории → «Рассчитать показатели». При желании сначала показать фильтр `абай 150`. Проверить подтверждённые группы → «Создать черновик». Исправить текст без вымышленных причин, «Сохранить текст», «Утвердить версию», подтвердить действие. Показать время, номер версии и контрольный отпечаток. «Это фиксированный снимок на момент утверждения. Для правки создаётся новая версия».

**4:30–5:00 — Экспорт.** Нажать «Экспорт CSV»; XLSX также доступен. Файл включает срез, реальные показатели, категории, территории, источники, статусы и подтверждающие ID. «Экспорт не пересчитывает утверждённую версию по новым данным».
